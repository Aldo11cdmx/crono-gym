# Cronos Gym — Command Center Vision

## Visión
Transformar Cronos Gym en un Command Center de entrenamiento: claridad, jerarquía visual, información contextual, navegación fluida. Identidad Obsidian + Crimson + Liquid Glass. Mobile-first. Offline-first.

## Secciones
- TODAY: centro de mando.
- TRAIN: ejecución.
- PLAN: planificación.
- PROGRESS: evolución.
- COACH: acompañamiento.
- PROFILE: cuenta.

## Principios
- Una sola implementación por pantalla.
- Un dueño por dato.
- Escribir es atómico.
- Degradación explícita.
- Bundle es presupuesto.
