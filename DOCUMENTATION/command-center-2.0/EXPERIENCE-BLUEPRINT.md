# Experience Blueprint

## Today (móvil)
1. Hero contextual (CTA).
2. Sesión activa/recuperación (si aplica).
3. Progreso semanal.
4. Resumen de rendimiento.
5. PRs recientes.
6. Último entrenamiento.
7. Cobertura muscular.
8. Tips/anuncios.

## Tablet
Hero full + 2 columnas (progreso | tips).

## Escritorio
Hero full + 2 columnas + fila inferior (PRs + historial).

## Reglas de experiencia
- No datos falsos.
- No repetir métricas sin propósito.
- No indicadores de recuperación sin datos.
- Priorizar siguiente acción.
- Respetar reduced motion.
- Mantener accesibilidad.
- Estados vacíos útiles.
- Diferenciar offline/cacheado/error.
