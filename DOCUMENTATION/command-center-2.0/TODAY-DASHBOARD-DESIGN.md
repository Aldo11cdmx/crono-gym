# Today Dashboard Design

## Composición (móvil)
1. Hero contextual (CTA).
2. Sesión activa/recuperación (si aplica).
3. Progreso semanal.
4. Resumen de rendimiento.
5. PRs recientes.
6. Último entrenamiento.
7. Cobertura muscular.
8. Tips/anuncios.
9. Coach (si coachId).

## Jerarquía tipográfica
TYPE.hero (una vez) → TYPE.subhead → TYPE.body → TYPE.caption.

## Espacios
SPACE.card (20), SPACE.section (32), SPACE.lg.

## Superficies
GlassCard (raised/flush), SURFACE.base (#000).

## Acento
ACCENT.base solo acción primaria. Ámbar solo advertencia.

## Animaciones
MOTION.fast/normal, spring/easeOut, transform+opacity.

## Accesibilidad
Contraste AA, foco visible, reduced motion.
